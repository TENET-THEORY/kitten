# Kitten website

Marketing/docs site for the Kitten CLI, generated with:

```bash
./gradlew :app:run --args='new website --package com.kittenmp.website --path . --type ktor'
```

## Run

```bash
./gradlew :ktor:run
```

Then open http://localhost:8080

## Docker

From the repository root (needs the sibling `ai` module):

```bash
docker build -f website/Dockerfile -t kitten-website .
docker run --rm -p 8080:8080 kitten-website
```
